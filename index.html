Tiny Book Notation Guide, Rev. 3

This guide describes a notation designed for tracking tasks and notes within a pocket-sized book without lines markers. This notation is designed to minimize both space usage and pen strokes while remaining legible at a glance.

1 Concepts

The format is comprised of an unordered but dated list of items. Items can be a task to complete, a shopping list, miscellaneous notes, or any other alphanumeric string.

1.1 The Bar

To add an item to the list, write a line or block of text in the next available space, typically directly below the last item. This text should be written with a blank margin on the left side to allow room for the bar.

After the text of an item is complete, delimit it by drawing a vertical line on the left side. This line is the bar and it should be drawn such that it envelops the full height of the text.

In addition to conveying the bounds of an item, the bar also conveys information about the state and class of the item. With no markings other than the obligatory bar, an item is considered to be a task in need of completion.

1.2 Modifiers

Modifiers are symbols added to the bar to convey additional information about an item. An item can only have one state, but can have multiple classes. Each symbol, whether a state symbol or class symbol, has one specific position on the bar. Some positions can hold multiple symbols, whereas others are exclusive to make invalid or conflicting information impossible to represent.

2 Modifier Symbols

2.1 State

State symbols are used to convey the state of an item. Only one can be present per item, placed in the center of the bar. The following states are possible:
State Symbol Symbol name Info
To-do None N/A Default state, indicates a task to complete.
Canceled Slash Indicates a canceled task.
Done Cross Indicates a completed task.
No action Circle Indicates an item requires no action. Used for notes.

2.2 Class

Class symbols are used to convey the class (i.e. type) of an item. Unlike states, items can have multiple classes. Each symbol has a designated position (side) it should be drawn on, and symbols that share the same position can be combined.
Class Symbol Symbol name Position Info
Critical Bang Left Indicates a task is of critical importance or its completion is urgent.
Unclear Query Left Indicates the task requires clarification or additional information.
Critical+Unclear N/A Left Combination of Critical and Unclear.
List Flag Right Indicates a list which may be expanded. The following item should be placed on the next page (leaving the rest of the current page blank) so that the list can be expanded as needed.
Void V ("Vee") Right Indicates that the item is void, e.g. no longer relevant, contains incorrect information, etc. Does not imply a task is canceled or completed, so the relevant state symbols should be drawn too.
List+Void N/A Right Combination of List and Void.

3 Dating

In order to make good use of relative dates and shorthand such as "tmrw." (tomorrow), "n. mon." (next monday), etc, it's necessary to keep track of the date each item was added. This is accomplished by writing the current date (in shorthand) on the right side of the current page in the next available position. This is called a date line. A horizontal line can optionally be drawn to the right of the date to improve legibility.

The month should always be shortened to three letters, but the year should always be written in full. With this scheme, it can be inferred that all three character strings in the date line are months, all one and two character strings are days, and all four character strings are years.

3.1 Minimum Updates

A new date line should be added only when you intend to add another item directly after it, in order to prevent writing redundant date lines with no following items. In addition, a new date line should only include components of the date that have changed since the previous date line. If the month has not changed, only day should be written. If the month has changed but the year hasn't, only the month and the day should be written. The only instances in which the year should be written are 1) on the first date line of the book, and 2) after the new year.

Note: The presence of ellipses (...) in this example implies at least one item in between date lines.
